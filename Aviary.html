A web browser for Windows 11

The web, kept under glass.

Aviary carries Safari's design language onto Windows — properly native, on Microsoft's own rendering engine. The window is Windows. Everything inside it is Safari.

Phase 1 · Shell C# · WinUI 3 · WebView2 No engine to bundle

Two looks, both Safari

Switchable at runtime, because Safari's own answer changed. Each pairs with a top tab bar or a vertical sidebar — four combinations, all of them real.



Liquid Glass

Safari 26 · macOS Tahoe · shown light

Chrome that floats above the page rather than sitting on it. Content scrolls underneath and the glass picks up its colour. Full-stadium corners, a specular rim that is bright at two poles and invisible at the flanks, and shadows in three layers.



Classic

Safari 15 – 18 · shown dark

One opaque plane welded to the top of the window. No gap, no gradient, no elevation, and a single hairline that only appears once you scroll. It takes the page's colour, and every glyph flips to white when that colour goes dark.

How it gets built

One phase at a time, with a sign-off between each — and two tracks. Alpha builds the thing; beta is where it becomes something you actually use.

How the features arrive

Not all at once. A quarter of the feature set lands in Phase 03, another quarter in Phase 04, and the remaining half in Phase 05 — the pre-release, where it has to actually be good, because Phase 06 is Beta Build 1 and people start living in it.

What it's built on

Decided up front, and not revisited. Every choice here is a trade the alternatives lose.

Language
C# · .NET 9

Native, no runtime for the user to install.

Interface
WinUI 3

Real Mica, real rounded corners, real caption buttons.

Engine
WebView2

Edge's Chromium, already on every Windows 11 machine.

Ships as
One .exe

Double-click. Around 170 MB, because .NET and WinUI travel with it — so you install nothing.

Why not Electron

  • WebView2's Evergreen runtime already ships with Windows 11 — nothing to bundle.
  • DRM works. Netflix and Spotify play, because this is Edge's engine.
  • About 20 MB instead of about 200.
  • Mica is real, not a screenshot of a blur.

Why not actual WebKit

  • No Widevine, so half the web's video simply refuses to play.
  • Video codecs are broken on Windows in every build worth having.
  • No WebGL.
  • Worth revisiting only much later, as an optional "render this page in WebKit".

Aviary ships Safari's user agent, so sites serve their Safari code paths. The engine underneath is still Chromium — that is a deliberate, and slightly dishonest, trade, and it will be a per-tab toggle rather than a silent default.

Getting a copy

Aviary runs. It opens tabs, browses the live web, sends Safari's user agent, and has a settings page of its own — all verified by driving the real app. There is an Aviary shortcut on the desktop; automatic downloadable builds land once the project has a GitHub home.
