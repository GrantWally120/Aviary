Two looks

Both of them Safari.

Switchable while the browser runs, because Safari's own answer changed. Each pairs with a top tab bar or a vertical sidebar — four combinations, all of them real.

Liquid Glass

Safari 26 · macOS Tahoe · shown light

Chrome that floats above the page rather than sitting on it. Content scrolls underneath and the glass picks up its colour. Full-stadium corners, a rim that is bright at two poles and invisible at the flanks, and shadows in three layers.

Classic

Safari 15 – 18 · shown dark

One opaque plane welded to the top of the window. No gap, no gradient, no elevation, and a single hairline. It takes the page's colour, and every glyph flips to white when that colour goes dark.

How it gets built

Two phases. Then it's yours.

Phase 1 builds the thing, one build at a time, with a sign-off between each. Phase 2 is where it becomes the browser you actually open. Pick any build to see what it brought.

How the features arrive

Not all at once. A quarter of the feature set lands in Alpha Build 3, another quarter in Alpha Build 4, and the remaining half in Alpha Build 5 — the pre-release, where it has to actually be good, because next comes Beta Build 1 and people start living in it.

What it's built on

Decided once. Not revisited.

Every choice here is a trade the alternatives lose.

Language
C# · .NET 9

Native, with no runtime for you to install.

Interface
WinUI 3

Real Mica, real rounded corners, real caption buttons.

Engine
WebView2

Edge's Chromium, already on every Windows 11 machine.

Ships as
One folder

Double-click. Around 170 MB, because .NET and WinUI travel with it — so you install nothing.

Why not Electron

  • WebView2's Evergreen engine already ships with Windows 11 — no second copy of Chromium to carry.
  • DRM works. Netflix and Spotify play, because this is Edge's engine.
  • The engine keeps itself up to date with Windows, not with Aviary.
  • Mica is real, not a screenshot of a blur.

Why not actual WebKit

  • No Widevine, so half the web's video simply refuses to play.
  • Video codecs are broken on Windows in every build worth having.
  • No WebGL.
  • Worth revisiting only much later, as an optional "render this page in WebKit".

Aviary sends Safari's user agent, so sites serve their Safari code paths — and the extra Chromium details that page scripts could read are taken away. The engine underneath is still Chromium: a deliberate, slightly dishonest trade, and a switch in Settings rather than a silent default.

Getting a copy

Aviary runs. It browses the live web, blocks ads and trackers site by site, searches with the engine you choose, and carries its own settings, updates and diagnostics — all checked by driving the real app. There is an Aviary shortcut on the desktop; downloadable builds arrive once the project has a home on GitHub, at the end of Alpha Build 5.

Aviary is a working name and an independent project. It is not affiliated with Apple, and it is not Safari — Apple owns that mark. Windows, WinUI and WebView2 are Microsoft's.
