Version one, forever

There is no v2

Versions run 1.0.0 → 1.9.9 and stop there: a hundred releases of runway. Six or more changes make a minor step, five or fewer a patch. The self-test fails on anything outside the range, so a stray 2.0 cannot ship — and if 1.9.9 is ever reached, the engine says so at boot.

Why it isn't a tab

And how to run it

It's a toolbox, not a game.

WallyCore1 is copied into a Godot project and games are built on top of it, so there is nothing for a browser to open. Its demo exercises every system and runs in Godot — press F1 there for the What's New panel you can see here, and F3 for the debug overlay.

Double-click the launcher menu and choose Play the demo:
