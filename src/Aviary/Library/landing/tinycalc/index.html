TinyCalc

Calculator minimus, Windows — one C file, no runtime.

A whole desktop calculator — keypad, memory, backspace, sign, percent, keyboard shortcuts — in a program smaller than most icons. It can't run inside a browser, so here is a faithful copy to try: same maths, same errors, same keys.

How it gets there

From the build script and the source
No runtime

It never loads the C library

Linked with /NODEFAULTLIB and started at its own CustomEntryPoint, ending with ExitProcess. Only kernel32 and user32 are imported.

Clang -Oz

Compiled for size, 32-bit

An i686 build at -Oz with no unwind tables, no compiler ident, merged constants, and every function in its own section so the linker can drop what is unused.

lld-link

Nothing to relocate

/fixed removes the relocation table and /MERGE folds sections together, saving 512-byte blocks — tested combination by combination, because one version of the linker crashed on it.

No tables

A key is its own ID

The keypad is the string 789/456*123-0C=+; each button's command ID is its character, so the dispatcher needs no lookup table. Memory buttons are 200–203.

Honest maths

Error, never nonsense

Everything is a 32-bit integer. Overflow and divide-by-zero show Error instead of wrapping round, and the one division x86 would crash on — the smallest number divided by −1 — is caught first.

Keyboard

An accelerator table

Buttons take focus when clicked, so a key handler would miss typing; an accelerator table catches keys wherever focus is and sends the same command a click would.
