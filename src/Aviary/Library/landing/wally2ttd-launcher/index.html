The Launcher

A zero-install desktop deck for the whole Complete Edition. It finds every build in its folder, watches for new ones, keeps score of what you play — and reads your rig down to the RAM sticks.

WALLY2TTD LAUNCHER · v0.9.1Command deck online
The systems check the launcher runs on start — replayed here. The real one checks real things.

What it does

Everything a tab isn't allowed to
Finds

Every build, found

Scans its folder and Archive/ for every .html and .exe build. One the edition expects but can't find becomes a NOT DETECTED card, with the path it belongs at.

Watches

Live folder watch

Drop a build in and it appears; take it out and it goes — no restart. It never lists itself.

Keeps score

Your play, counted

Launches, total playtime and last played for every build, a TOP badge on your most-played, and sorting by version, recent or played.

Self report

Builds speak for themselves

A build can declare its own version track; the deck reads it straight out of the game file and shows it as a chip — v1.8 Remastered's build number updates itself.

Scan PC

Reads your rig

One click: CPU cores and clock, GPUs and VRAM, motherboard, BIOS, every drive, the RAM layout and speed, monitors and refresh rates — in the background, so the deck never freezes.

Zero installs

Built with what Windows has

Compiled by the csc.exe that ships with Windows — deliberately C# 5 — with a WebView2 face. Nothing to install before it runs.

Why it isn't a tab

And where it lives

A web page may never do what it does.

The launcher lists folders, starts programs, times how long they run and asks Windows about your hardware. A browser tab is not allowed to do any of that — which is exactly what keeps a tab safe. So the launcher lives on your desktop, and this page lives here.
