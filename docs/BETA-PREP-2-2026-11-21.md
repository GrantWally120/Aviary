**Approved.** Grant was given the Terms of Use, the Copyright notice and the Privacy Policy to read and answered "Approved" on

The draft he was given to read stays on his PC (`docs/legal/`, ignored by Git, because it carries notes written to him). The

**Rules for whoever works on this next:**

1. Do not change a sentence of the Terms, the Copyright notice or the Privacy Policy without showing Grant the new wording first.
2. When the Terms change, change `LegalTexts.TermsRevision`. The screen compares the revision, so everybody is asked again,
   which is what section 12 of the Terms promises.
3. Regenerate the three published files, never type them by hand:
   `dotnet run --project tools/test/security/SecurityHarness.csproj -c Release -- write-legal`

**The "I agree" screen** (`MainWindow.Terms.cs`): shown when a window finishes loading and the profile has not agreed to the
current revision. It comes up before the window makes its first tab, and `CreateTabAsync` refuses to make one until it is
answered, so there is no engine and no page behind it. "I agree" saves `termsAccepted` (the revision) and `termsAcceptedOn` (the
day) in `settings.json`; "Quit Aviary" closes the window; Esc is not an answer. "Reset settings" keeps the record.
A third key, `legalNoteSeen`, remembers that the Start Page's one-time note was read; the note comes back once whenever the
Privacy Policy or the Terms get a new revision.

**The test hook:** a test cannot press a native dialog through the DevTools port, so `AVIARY_TEST_TERMS=accepted` answers it,
honoured only together with `AVIARY_PROFILE_DIR` (a scratch profile). Every launcher in `tools/test` sets it;
`launch-quiet.ps1 -ShowTerms` leaves the screen up, and `terms-gate-test.ps1` answers it through UI Automation (18 checks).

## The Privacy Policy rule

A build that starts to **store or send** anything it did not before changes the policy in the same build: the sentence that
describes it, a new line at the top of `PrivacyPolicy.Changes`, a new `Revision`, and `ReviewedForVersion` set to the build's
version. A build that changes nothing of the kind still sets `ReviewedForVersion`. `tools/test/release-state-test.js` fails when
the reviewed version is not the version being built, so a build cannot be made on a policy nobody re-read.

What this update added to the policy: the record of agreeing to the Terms; the Start Page search bar (same rules as the address
bar); Bird News summaries and the three optional topics, and that it fetches no pictures; Quik's two startup timings
(`quik-stats.json`); the answers given to sites that asked for location, camera, microphone or notifications; skipping tracking
redirects and its limit; the maker named as Grant at Wally Studios.

## The search bar (studied from Brave)

Brave's new tab page has a search box in the page itself, apart from the address bar. Aviary's: a field under the Aviary mark
on the Start Page. A new tab leaves the keyboard in it, typing anywhere on the Start Page lands in it, the arrow keys walk its
list, Enter searches. The address bar is unchanged and one click (or Ctrl+L) away.

- It sends nothing until Enter, unless "Search suggestions from the engine" is on, and then under exactly the address bar's
  rules: only to the chosen engine, never an address, never from a private window, no cookies, no redirects.
- Something typed that is an address is opened, by the same code the address bar uses (`MainWindow.Navigate`), and is never
  sent to the search engine as words.
- Settings → Get started: **Show the search bar** (`startSearch`) and **Typing on a new tab goes to** (`newTabTyping`).

## Safety Check, and the two new protections

Safety Check gained an `Area` on every finding, a fourth level (`tip`: a stronger setting that costs something, offered and never
counted against the score), a score ring, four groups, "Fix everything" (`safetyFixAll`), and checks for link pings, tracking
redirects, pop-ups, what websites may ask for, SmartScreen, the sites allowed to load without a secure connection (with "Forget
them"), saved passwords and form entries.

**Skip tracking redirects** (`skipBounces`, on by default): for a short list of redirect pages that only count clicks (Google's
`/url`, Facebook's `l.php`, Instagram, YouTube, DuckDuckGo, Reddit, VK, LinkedIn and a few more), the tab goes straight to the
address written in the link. The destination must be a complete http(s) address on a different site. Link-scanning services
(Microsoft Safe Links, urldefense, Steam's link filter) are deliberately not on the list, and shorteners cannot be skipped
because their links do not contain the destination. Limit: a link the engine has already started to open before Aviary sees it
(one a website opens in a new tab) can still reach the redirect page first. The policy says so.

**What websites may ask for** (Settings → Content): Ask or Block for location, camera, microphone and notifications. Block
refuses every site without a question, saves nothing for the site, and takes back grants given earlier
(`CoreWebView2Profile.SetPermissionStateAsync`). "Forget every answer" takes back every saved answer.

## Prism 2, and the "Safari look" wording

"Liquid Glass" is "Prism 2" wherever a person reads it: Settings, the release notes, the Start Page, the landing page. The
setting's saved value is migrated when settings load, and `Looks.IsGlass` still understands the old name, so old profiles and
old test seeds open in the right look. Code names for parts stay (`Themes/LiquidGlass.xaml`, `GlassCapsule`).

"Safari look" is "Look", with a small picture of each look to press. Descriptions say what a thing does instead of which
browser does it. "Identify as Safari" keeps its name: it really does send Safari's user agent.

## Bird News

- **Its own page:** tabs by place and topic, a filter, a button per publisher, the newest story given room, the rest grouped
  by when, Check now, and a mark that puts a story on the Reading List.
- **Summaries:** each publisher's own short description from the same feed, as plain text, cut to about three lines.
  Never anything Aviary wrote.
- **Read stories are drawn fainter**, worked out on this computer from history. A private window is told nothing.
- **Topics:** Technology, Science and Sport from the same six publishers (twelve more feed addresses, each checked on 21 Nov).
  Each topic is one switch that names every publisher it asks, and each is off until switched on.
- No pictures are fetched; the Start Page's content policy still allows none from the network.

## Quik

- **This computer's numbers** in Settings → Quik: this launch's time, the last launch with Quik beside the last without, and
  new-tab times. `quik-stats.json` holds two timings and two dates, nothing else.
- **Ready tabs for pages Aviary opens** in a new tab (a favourite's "Open in New Tab", "Search for…", a tile's menu).
- **Keep recent tabs awake for** 15 minutes, 30 minutes, 1 hour or 2 hours (`quikAwakeFor`).

## Performance and Storage Usage

Measured against Windows on 21 November. Performance listed 8 processes where Windows had 9: the engine's own list leaves out
its crash reporter. `ProcessTree.cs` walks Windows' process list for the engine processes that descend from Aviary, so the
total matches, and reads each helper's command line so "Network, storage and sound" became "Network service", "Storage
service" and so on. Every process row says what the process is for. Storage Usage already matched Windows to the byte (checked:
286,599,957 bytes of program files and 11,793,427 bytes of profile, both exact); the files Aviary writes in the profile now each
have their own name instead of "Other Aviary files".
