Beta Prep 1 is a build of its own, not a note inside Alpha Build 5:

- `BuildInfo.PrepNumber = 1` makes the app call itself **Beta Prep 1** (code **BP1**), version **0.5.1**, everywhere the build is
  named: Settings → Updates ("You're on"), About, the Start Page and Get started rows, diagnostics' channel, the package name
  (`Aviary-BP1-...zip`) and the README that ships with the app.
- Alpha Build 5 (0.5.0, sixteen of sixteen milestones) is unchanged and now sits under **Earlier builds** in Updates. Its notes,
  milestones and the landing-page data for it were not touched.
- It keeps phase 5 underneath (`PhaseNumber` and `PhaseShipped` stay 5), so no Settings row changes meaning or badge.
- Its Updates entry is the one in `src/Aviary/InternalPages.cs` with `prep:1` (directly after Alpha Build 5). It has no
  milestone bar, because it is an update and not a numbered build; it shows the **Latest** chip.
- A later prep: add an entry with `prep:2` after it and set `PrepNumber = 2`; this one then moves to Earlier builds. When Beta Build 1
