# Beta Prep 1

Made on **Sunday 25 October 2026** (the work in it landed Wednesday 21 to Saturday 24 October). Version **0.5.1**.

Grant asked (on the evening of Saturday 24 October, before going to bed) for "a new update in Aviary, named Beta Prep 1, with
all the recent changes added in as one update; there will be more preps". After the first version he corrected it: **"Beta Prep 1
will replace the current AB5, it's a literal update"**, and asked for the dates to be verified. This is the second version.

## What it is

Beta Prep 1 is a build of its own, not a note inside Alpha Build 5:

- `BuildInfo.PrepNumber = 1` makes the app call itself **Beta Prep 1** (code **BP1**), version **0.5.1**, everywhere the build is
  named: Settings → Updates ("You're on"), About, the Start Page and Get started rows, diagnostics' channel, the package name
  (`Aviary-BP1-...zip`) and the README that ships with the app.
- Alpha Build 5 (0.5.0, sixteen of sixteen milestones) is unchanged and now sits under **Earlier builds** in Updates. Its notes,
  milestones and the landing-page data for it were not touched.
- It keeps phase 5 underneath (`PhaseNumber` and `PhaseShipped` stay 5), so no Settings row changes meaning or badge.
- Its Updates entry is the one in `src/Aviary/InternalPages.cs` with `prep:1` (directly after Alpha Build 5). It has no
  milestone bar, because it is an update and not a numbered build; it shows the **Latest** chip.
- A later prep: add an entry with `prep:2` after it and set `PrepNumber = 2`; this one then moves to Earlier builds. When Beta Build 1
  starts, set `PrepNumber = 0` and move to phase 6 as before.

**The card at the top of Updates works like Alpha Build 5's** (Grant, 25 Oct: "make it the same as alpha build 5. You can press it, and
it will open the description. The description will explain what it's there for, like what I did and what got fixed."). The
"You're on Beta Prep 1" card is a pressable card with a chevron, closed until pressed. Open, it shows a bar and eight numbered
**changes**, each with its day and a plain account of what was asked or found, what was done and what got fixed:
1 Privacy and security before any accounts (21 Oct) · 2 YouTube plays again (22 Oct) · 3 Everyday shortcuts and new tabs (22 Oct) ·
4 Prism 2, the look (23 Oct) · 5 Groundwork for accounts (23 Oct) · 6 Newer Windows parts (23 Oct) · 7 Fresh ad-blocker lists
(23 Oct) · 8 The PARALLAX signup really sends (24 Oct). They are the entry's `milestones` with `unit:'changes'`; a prep counts them
all as done (`renderUpdates`: `CURRENT.prep ? ms.length : ...`), and Alpha Build 5's own count (16 of 16) is untouched. The longer
notes stay below the card under "What's new in Beta Prep 1".
